Ultimate Generator Stats Plugin

This plugin lets you display live statistics for any Perchance generator — including your own or others. It supports multiple output formats, compact view counters, short/long time formats, badges, JSON output, and more.

Installation

Place this in your Perchance Code panel:

generatorStatsV1 = \{import:ultimate-generator-stats-plugin-v1\}

Basic Usage

Show stats for the current generator:

[generatorStatsV1("views")]
[generatorStatsV1("lastEditTime")]

Stats for Another Generator

Pass the generator name as the first argument:

[generatorStatsV1("dice-plugin", "views")]
[generatorStatsV1("background-image-plugin", "lastEditTime")]

Extended Data Types

The Ultimate version adds many new output formats:

[generatorStatsV1("viewsRaw")]          → raw integer
[generatorStatsV1("viewsShort")]        → compact (1.2K, 3.4M)
[generatorStatsV1("viewsCompact")]      → K / M / B formatting

[generatorStatsV1("lastEditTimeShort")] → short relative (3d, 2h, 5m)
[generatorStatsV1("lastEditTimeMs")]    → milliseconds since last edit
[generatorStatsV1("lastEditTimeIso")]   → ISO timestamp
[generatorStatsV1("lastEditTimestamp")] → raw epoch timestamp

[generatorStatsV1("badge")]             → "1.2K views • edited 3 days ago"
[generatorStatsV1("json")]              → full JSON stats object

Examples

Views: [generatorStatsV1("viewsShort")]
Last edited: [generatorStatsV1("lastEditTimeShort")]
Full badge: [generatorStatsV1("badge")]

Other generator:
[dice-plugin] → [generatorStatsV1("dice-plugin", "badge")]

Notes

  • All original plugin behavior is fully supported.
  • Works with any public Perchance generator.
  • Automatically caches results for performance.
  • Outputs update asynchronously once data loads.
